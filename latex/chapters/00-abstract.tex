\begin{abstract}
Cross-view object correspondence is a fundamental task for multi-camera intelligent vision systems. It aims to identify the same physical object across cameras despite drastic differences in scale, lighting, and visibility, all while lacking camera geometric calibration. This task is attracting a growing body of work, and some methods already achieve respectable results. However, all published solutions rely on an architectures trained directly on cross-view datasets. This makes them inapplicable to novel camera configurations and leaves their predictions difficult to interpret, since the reasoning behind any single segmentation is locked inside model parameters and abstract vector representations. 

In this thesis, we ask whether natural language can serve as a bridge between machine learning architectures, making text a simple yet effective information compression mechanism. In particular, we test this hypothesis within the cross-view object correspondence task, exploring whether natural language descriptions of an object can drive its segmentation across different camera views. This framing is motivated by how humans collaborate through natural language and by the interpretability that language provides. To date, no other work has explored this paradigm, making this thesis a genuine contribution to the field.   

We present a fully training-free pipeline in which natural language serves as the bridge between viewpoints. A vision-language model describes the target object using view- and time-independent terms; an open-set detector grounds that description to select anchor frames in the destination view; Segment Anything Model~3 Agent segments and propagates the mask across frames. No component is fine-tuned, and the bridge between views is a human-readable phrase that renders every intermediate decision inspectable. We benchmark our approach against published methods on the Ego-Exo4D correspondence challenge, reaching within a few percentage points of the 2025 challenge winner, and provide a detailed ablation study examining where foundation models succeed and where they remain limited on a task none were designed for.

The thesis develops these contributions across five chapters. A theoretical chapter first establishes the mechanistic foundations of each pipeline component, covering transformers, visual representation learning, self-supervised features, promptable video segmentation with the Segment Anything family, language-grounded open-set detection, large language and vision-language models, and Agent design. We then survey related work and formally define the correspondence task, present the proposed pipeline with motivation for each design choice, and close with experimental results, ablation analyses, and a discussion of limitations, which pave the way for future work. Together, these results show that foundation models mediated by language offer a viable, interpretable, and training-free alternative for cross-view object correspondence, a task dominated by specialised learned architectures. More broadly, they suggest that natural language can act as a reliable bridge between machine learning architectures, confirming our hypothesis and opening this novel paradigm to future research.
\end{abstract}
