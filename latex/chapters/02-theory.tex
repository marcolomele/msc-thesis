\chapter{Theory}
\label{chap:theory}

Composing foundation models at inference time presupposes that each model already encodes a competent solution to the sub-problem it was built for. Before we can justify the pipeline of \hyperref[chap:pipeline]{Chapter~4}, we therefore need to understand what these models learned and why their representations transfer to a task none of them was designed for. This chapter builds that understanding from the ground up, following the same dependency chain that the pipeline itself traverses.

The chain begins with a single primitive. In order to segment objects across videos we must segment them in individual frames, and in order to segment them in frames, we must first represent each image numerically. From that representation, segmentation extracts the spatial extent of a single object, yet a segmenter alone cannot decide which object to extract when the same scene is observed from two unrelated viewpoints. Language supplies the missing bridge, because a description of an object is invariant to the perspective from which the object is seen. A description, however, only mediates a correspondence if some controller orchestrates the visual models that produce and consume it, which is the role of agentic composition. Finally, none of these components operates on a still image alone; the task unfolds in video, so the representations must be propagated through time. Each section that follows resolves one link in this chain and exposes the limitation that motivates the next.

We open with visual representation (\cref{sec:visual-representation}), building from the Transformer to the vision backbones that encode an image as a vector of fixed length called an \textit{embedding}, and showing how the most transferable of these representations are learned without any supervision. We then turn to segmentation (\cref{sec:segmentation}), tracing the path from architectures specific to a single dataset to promptable models that segment arbitrary objects on demand. Next, we cover language grounding (\cref{sec:language-grounding}), the machinery that aligns visual content with natural language and lets a description localise an object. Subsequently, we examine the foundation model paradigm and the agentic loops that coordinate these models into a working system (\cref{sec:foundation-models-agents}). We close by surveying the related work that has already addressed cross-view object correspondence (\cref{sec:related-works}), which reveals the gap our pipeline is built to fill.
