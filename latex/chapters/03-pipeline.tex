\chapter{Proposed Pipeline}
\label{chap:pipeline}

In the previous chapter, we built a detailed understanding of each foundation model our pipeline relies on, finishing with Segment Anything Model 3 (SAM 3) and its Promptable Concept Segmentation (PCS) capabilities powered by a Vision Language Model (VLM) embedded in an agent loop. Then, we reviewed the existing methods for cross-view object correspondence, exploring their modules for feature fusion across views. Finally, we revealed the common limitation: all previous methods train a dedicated component on paired ego-exo data, which neither transfers to a new camera configuration nor provides the information needed for interpretability studies (\cref{subsec:common-limitations}). Motivated by these findings, in this chapter, we present our pipeline that leverages natural language as the sole signal for bridging between the two views. We begin by formalising the cross-view object correspondence task, and then describe how the four key elements of the pipeline (Source Frame Selection - \cref{subsec:Stage1}, Target Object Description - \cref{subsec:Stage2}, SAM 3 Agent Segmentation - \cref{subsec:Stage3}, Mask Prediction Propagation - \cref{subsec:Stage4},) work together to solve it.

\section{Task Formulation}
\label{sec:task-formulation}
% ------------------------------------------------------------

Let $\dataset = \{\take_1, \ldots, \take_{|\dataset|}\}$ represent the Ego-Exo4D dataset as a collection of takes (\cref{subsec:datasets}). A take $\take \in \dataset$ is a single scene recorded simultaneously by a set of cameras $\set{C}$ synchronised in time, so that each instant is observed from $|\set{C}| \geq 2$ perspectives at once. Each camera $c \in \set{C}$ is either egocentric or exocentric and records a video $\vv{I}^c = (I^c_1, \ldots, I^c_\nframes)$, where $\frameidx \in \{1, \ldots, \nframes\}$ indexes the images (a.k.a. frames), and the synchronisation guarantees that $I^c_\frameidx$ and $I^{c'}_\frameidx$ capture the same moment for any two cameras $c, c' \in \set{C}$. By definition of the cross-view object correspondence task, a single run uses exactly two of these cameras, the source $S$ and the destination $D$, with one egocentric and the other exocentric, and therefore it operates on their videos $\vv{I}^S$ and $\vv{I}^D$. A target object is annotated in the source view by a \textit{masklet}, a track of binary masks $\{\mask^S_\frameidx\}_{\frameidx \in \set{T}}$, where each $\mask^S_\frameidx \in \{0,1\}^{H \times W}$ indicates which pixels in the image are the object and $\set{T} \subseteq \{1, \ldots, \nframes\}$ is the set of annotated frames. Given this input, the pipeline must predict the corresponding mask track in the destination view, namely a mask $\hat{\mask}^D_\frameidx$ for every frame $\frameidx$, whether or not the object is annotated or even visible there. Each run therefore addresses one triplet $(\take, o, d)$ of a take $\take$, a target object $o$, and a direction $d$. The latter represents which perspective is source and which is destination, with $(S=\text{egocentric}, D=\text{egocentric})$ for \textit{Ego2Exo}, and viceversa for \textit{Exo2Ego}.

This single objective blends two orthogonal challenges. This pipeline separates them cleanly. The first is cross-view transfer, so relating the object across the extreme change in viewpoint, scale, and surrounding context that disconnects the egocentric and exocentric perspectives. The same cyan cutting board may fill the frame in one view and shrink to a handful of lateral pixels in the other. The second is temporal completeness, meaning assigning a mask to every destination frame, including the many frames where the object is partially occluded, blurred by motion, or completely missing from the view. Cross-view transfer is the harder and the more specific of the two, because no geometric or photometric regularity reliably survives the viewpoint variability, and no camera calibration is available. Oppositely, temporal completeness is a tracking problem that video segmentation based on memory already solves well once a few reliable masks are available, as we saw with SAM~2 in \cref{sec:addition-of-time}.

Our design follows this split. Most of the pipeline is dedicated to cross-view transfer by aiming at producing a small set of reliable masks in the destination view, while temporal completeness is delegated to SAM~2's native video tracker. The core research contribution by our work is evaluating whether natural language can serve as a bridge to transfer the object's mask across the viewpoint difference. First, we identify the optimal frame in the source view, then we generate a description of the target object using a VLM, and finally we leverage SAM~3' PCS along with its agent interface to turn the description into the mask for the target object in the destination view.

\section{Method Overview}
\label{sec:method-overview}
% ------------------------------------------------------------

The pipeline processes each triplet through four sequential stages, illustrated in \cref{fig:pipeline}. First, a set of seed frames is selected from the source video $\vv{I}^S$, choosing the frames in which the target object is most clearly visible (Stage~1). Then, a vision-language model reads those seed frames and writes a description of the object that is meant to hold independently of viewpoint and time (Stage~2). Next, this description guides the selection of a set of anchor frames in the destination video $\vv{I}^D$, and an independent SAM~3 agent loop segments the object on each of them (Stage~3). Finally, the resulting anchor masks are propagated across the remaining frames of $\vv{I}^D$ by the video tracker (Stage~4). The first three Stages carry out the cross-view transfer; the last completes the track in time.

\subsection{Source Frame Selection}
\label{subsec:Stage1}

The quality of the object description produced in Stage~2 depends directly on how clearly the target is shown to the language model. Therefore, we pick the $K$ frames from the source view where the target object is most visible. 

This dependence is rooted in how the model encodes an image. As we saw in \cref{subsec:vit}, a Vision Transformer partitions the frame into a fixed grid of non-overlapping patches and embeds each as a token, so an object that fills more of the frame is covered by more patch tokens and therefore claims a larger share of the resulting representation. A larger, clearer target consequently carries greater semantic weight in the embedding the language model reads, leaving it far more to describe than a small or peripheral one. That dependence makes the choice of source frames the first thing the pipeline must get right. As a result, rather than passing the model every annotated frame, which is redundant and costly, we score each annotated frame $I^S_\frameidx$ from its ground-truth mask $\mask^S_\frameidx$ and keep only the best. The score is a weighted combination of two visual cues computed on the mask,
\begin{equation}
  q(\frameidx) = w_\alpha \, \alpha(\mask^S_\frameidx) + w_\beta \, \beta(\mask^S_\frameidx),
  \qquad \frameidx \in \set{T},
  \label{eq:frame-score}
\end{equation}

where $\alpha(\mask^S_\frameidx)$ is the normalised mask area, the fraction of the frame occupied by the object, and $\beta(\mask^S_\frameidx)$ is centrality, defined as the complement of the normalised distance between the mask centroid and the frame centre, with value approaching one when the object sits at the middle of the image. The weights are set to $w_a = 0.99$ and $w_c = 0.01$, making area the dominant factor and leaving centrality as a marginal tie-breaker that prefers an object nearer the frame centre only when two frames are otherwise comparable. This ordering reflects a simple observation, namely that a large object gives the language model far more to describe than a small but perfectly centred one. The $K$ frames that score highest form the seed set $\set{S} \subseteq \set{T},\,\abs{\set{S}}=K$, and their masks $\{\mask^S_\frameidx\}_{\frameidx \in \set{S}}$ are used to build the annotated images passed to Stage~2. We validate this formulation against a more elaborate alternative in the ablations of \cref{chap:experiments}.

\subsection{Target Object Description}
\label{subsec:Stage2}
Having found the source frames with the clearest view of the target object, the pipeline proceeds with generating a textual description of the object via a VLM. For the bridge to carry the object across the viewpoint gap, the description must satisfy two properties at once. It must hold under \emph{view independence}, remaining valid when the object is seen from the radically different viewpoint of camera $D$, and under \emph{time independence}, holding for every destination frame $I^D_\frameidx$ rather than only those moments close in time to the seed frames. The second property is what makes the description usable for selecting  frames in destination view, which we call anchors, in Stage~3. The extreme change in viewpoint gives no guarantee that the destination frames synchronised with the seed frames are themselves good places to segment/ In short, there is no reliable symmetry in quality between the two views, so a description holding to one moment in the source view would mislead the search in the destination view.

To satisfy both properties, we instruct the model to report only intrinsic attributes of the object, namely its colour, canonical identity, material, and structural parts, all of which stay constant under changes of camera perspective and time. For each selected seed frame $I^S_\frameidx$ with $\frameidx \in \set{S}$, the model receives two images, one with the mask $\mask^S_\frameidx$ overlaid as a translucent red region outlined by a contour, and one in raw form, so that it can locate the target without losing the unaltered appearance around it. 

This pairing is not only an empirical preference but follows from how the model represents an image. Qwen learns to localise objects from region-description training that emits coordinates in a normalised string format (\cref{subsec:llm}), so a coloured overlay is not the grounding signal it was trained on. Placing a masks impacts the very patches covering the object, the same tokens that, as we saw in \cref{subsec:vit}, encode its colour and material, the intrinsic attributes the description must report. The overlaid frame therefore points the model at which object to describe while degrading how that object looks, whereas the raw frame restores its appearance, which is why supplying both yields the higher overlap rather than either image on its own. The model returns a description $w_\frameidx$ for each seed frame in JSON format. We confirm these choices in \cref{chap:experiments}, showing that descriptions satisfying both independence properties lead to better anchor selection downstream, and that other contents of the description hurt performance.

\subsection{SAM 3 Agentic Grounding}
\label{subsec:Stage3}

Stage~3 splits into two steps, choosing first where to look and then segmenting what is there. The first step scores every destination frame by how likely it is to contain the target, using either of two interchangeable signals. Grounding DINO scores each frame $I^D_\frameidx$ by running open-vocabulary detection with the description $w_\frameidx$ as the query, which gives a visibility signal grounded in language (\cref{subsec:groundingdino}). RoMa offers the geometric alternative, scoring each frame by how many pixels of the source object find a confident match within it,

\begin{equation}
  s(\frameidx) = \sum_{\vv{x} \,:\, \mask^S(\vv{x}) = 1} \mathbbm{1}\!\left[\, c_\frameidx(\vv{x}) > \delta \,\right],
  \label{eq:roma-score}
\end{equation}

where $(\warp_\frameidx, c_\frameidx)$ is the warp field of \cref{eq:warp} estimated between the source frame and the destination frame $I^D_\frameidx$, the sum runs over the source pixels $\vv{x}$ that lie inside the object mask $\mask^S$, and the indicator counts a pixel only when its match confidence $c_\frameidx(\vv{x})$ exceeds a threshold $\delta$. A frame thus scores highly when much of the source object is confidently visible somewhere within it, a visibility signal free of any language. In both cases the frames that score highest form the anchor set $\set{A} \subseteq \{1, \ldots, \nframes\}$. 

Each anchor frame is then segmented independently by a SAM~3 agent loop, with the same model from Stage~2 acting as its orchestrator (\cref{subsec:react,subsec:sam3}). The model first simplifies the rich description $w_\frameidx$ into a short noun phrase, since SAM~3 grounds a discriminative phrase far more reliably than a paragraph of attributes. This preference follows from how vision-language alignment is learned. The contrastive objective of \cref{subsec:multimodality} ties a whole sentence to a whole image through a single pooled embedding, so a concise noun phrase concentrates the query on one concept, whereas a paragraph of attributes spreads it across many and dilutes the match that grounding depends on. SAM~3 then segments every instance matching that phrase in the anchor frame, and the model inspects the resulting masks one by one, accepting or rejecting each against the original description. When every candidate is rejected, the loop restarts with a differently simplified phrase, so that a single poor prompt does not abort the frame. The mask accepted at convergence on each anchor frame yields the anchor mask set $\{\hat{\mask}^D_\frameidx\}_{\frameidx \in \set{A}}$, which anchors the propagation of Stage~4 by supplying concrete examples of the object's appearance and location in the destination view.

\subsection{Predicted Mask Propagation}
\label{subsec:Stage4}

A handful of anchor masks scattered through the destination video do not yet make a complete track. The goal of stage 4 is temporal completeness. We propagate the anchor masks $\{\hat{\mask}^D_\frameidx\}_{\frameidx \in \set{A}}$ across the remaining frames using SAM~2's video model, which conditions each new prediction on a memory bank rather than on the immediately preceding frame alone (\cref{sec:addition-of-time}). The bank holds both the anchor frames, to which masks have been assigned, and the frames most recently processed during propagation. At each frame $I^D_\frameidx$ with $\frameidx \notin \set{A}$, the model attends over this entire memory through cross-attention and predicts the mask from whichever stored frame best matches the current appearance of the object. This design suits egocentric video in particular. Rapid camera motion and frequent brief occlusions mean the frame just before $I^D_\frameidx$ is often not the most informative reference, and attending over the whole memory lets the tracker reach back to a distant anchor when the nearby frames fail.

For robustness, the pipeline holds every anchor in memory, and each frame draws on the anchor most similar to it via attention. We propagate bidirectionally. One pass runs forward from the earliest anchor $\min \set{A}$ to the end of the video, and another runs backward from the latest anchor $\max \set{A}$ to the start. Both passes carry all the anchors, so either one can reach any frame, but they approach it from opposite sides. For each frame we keep the prediction from the pass that reaches it from its nearest anchor, so the chain of frames separating a prediction from the anchor it leans on stays short,

\begin{equation}
  \hat{\mask}^D_\frameidx =
  \begin{cases}
    \hat{\mask}^{\rightarrow}_\frameidx, & a^\ast(\frameidx) \leq \frameidx,\\[2pt]
    \hat{\mask}^{\leftarrow}_\frameidx, & a^\ast(\frameidx) > \frameidx,
  \end{cases}
  \label{eq:mask-select}
\end{equation}

where $\hat{\mask}^{\rightarrow}_\frameidx$ is the mask from the forward pass, $\hat{\mask}^{\leftarrow}_\frameidx$ the mask from the backward pass, and $a^\ast(\frameidx) = \operatorname*{arg\,min}_{a \in \set{A}} \abs{\frameidx - a}$ is the anchor nearest to frame $\frameidx$. When that anchor sits at or before the frame, the forward pass is the one that travelled the shorter distance to reach it, so we trust its mask; otherwise the backward pass approached from the nearer side and we take its prediction instead. Choosing the pass with the shorter path to a reliable anchor keeps accumulated tracking drift low, which matters most in the long gaps between anchors where errors compound. Any non-empty predicted mask at a frame is recorded as the pipeline's prediction for the target object there, completing the destination track.

The four Stages together turn a sparse source annotation into a full destination track without training any component for the task, and every intermediate output remains open to inspection, from the seed frames to the description to the anchor masks. This readability lets us decompose the pipeline's performance in \cref{chap:experiments}. In the next chapter, we measure our performance against related works in the field, decompose the contribution of each stage to the final accuracy, compare the two anchor signals against random selection, and trace the dominant failure modes back to the stage that produced them with a detailed interpretability analysis.
